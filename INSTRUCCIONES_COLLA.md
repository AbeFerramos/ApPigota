# 📱 La Pigota - Instrucciones para la colla

## 🚀 Cómo acceder a la aplicación

### Paso 1: Conectarse a la misma WiFi
Conecta tu móvil al mismo WiFi que el ordenador donde está la aplicación.

### Paso 2: Abrir la aplicación
En tu navegador (Chrome, Safari, etc.), escribe:

```
http://192.168.0.68:8080
```

### Paso 3: Usar la aplicación
- ✅ Todos los cambios se guardan automáticamente
- ✅ Se sincronizan entre todos los dispositivos
- ✅ Funciona como una app nativa

## ⚠️ Importante

- Solo funciona cuando están en la misma WiFi
- El ordenador con la aplicación debe estar encendido
- Mantén la aplicación abierta en el ordenador

## 💡 Trucos

- **Instalar como app**: En Chrome (Android) o Safari (iOS), puedes "Añadir a pantalla de inicio" para que parezca una app real
- **Offline**: La app funciona sin internet, pero solo sincroniza cuando hay conexión

## 🆘 Problemas

**No puedo acceder:**
- Verifica que estás en la misma WiFi
- Verifica que el ordenador esté encendido
- Pregunta si la aplicación está funcionando

**Los cambios no se sincronizan:**
- Espera unos segundos (tarda hasta 2 segundos)
- Verifica que tengas conexión a internet
- Recarga la página
